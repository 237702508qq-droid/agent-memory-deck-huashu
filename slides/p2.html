问题现象

两个典型问题

提示词写得再详细，Agent 也未必懂你 —— 它缺少「桌面里」的记忆

问题 1

用户提供很多提示词，
但 Agent 的输出效果仍然较差

案例提示词（描述得很详细）
「我是云桌面的产品经理，写一个 VDI 相关的需求文档，主要针对 xx 客户提出的 xxx 移动端的问题」

内容比较空

专业名词的理解存在偏差

文档的格式不是我想要的

内容超出我的工作边界

!

公司通常构建企业上下文让 Agent 理解企业业务；但 Agent 不理解个人的偏好、工作边界、常用词，依然无法高质量输出。

问题 2

很难通过模糊指令达成目标 ——
办公桌面上发生的事情 Agent 并不知道

（Agent 只知道对话框里的事情）

案例提示词
「昨天张三发了我一个 PPT，名字好像是"什么什么 云桌面 xx 方案"，请使用这个数据帮我生成一份需求文档，就按照我昨天输出的那个需求文档格式来就行」
AGENT 只能反问

昨天的需求文档是什么格式？昨天张三是在哪里发的这个 PPT？
—— Agent 和人的记忆不一致，面对模糊指令就不知怎么办。

Agent 记得的 · 只是对话框
桌面里发生的 · 全部空白

桌面上发生的每一件事，都是 Agent 应该记得却记不了的记忆
